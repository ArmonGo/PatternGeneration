# PatternGeneration


This repository contains the implementation presented in:

A Multi-agentic Framework for Automated Ornamental Pattern Analysis and Decomposition

Abstract: Classical approaches to ornamental pattern analysis, such as image segmentation, shape and contour analysis, and geometric transformation detection, often encounter difficulties when dealing with highly complex, fragmented, or irregular motifs. To address these challenges, we develop a coordinated agentic system that identifies complex ornamental patterns and proposes possible segmentations, combined with computer vision techniques to discover the underlying compositional structures. The results demonstrate that integrating agents with computer-vision-based splitting yields clean sub-motifs from complex ornamental patterns, facilitating further analysis and reconstruction.
